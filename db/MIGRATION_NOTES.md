# Migration Notes: SQLite/LibSQL Prototype to PostgreSQL Enterprise

## 1. Type Mappings & Precision
- **Primary Keys:** Converted from SQLite `integer primary key` to PostgreSQL `BIGINT GENERATED BY DEFAULT AS IDENTITY`.
- **Booleans:** Converted from SQLite integer `0/1` to native PostgreSQL `BOOLEAN`.
- **Timestamps:** Converted from SQLite text strings to native `TIMESTAMPTZ` with microsecond accuracy, defaulting to `CURRENT_TIMESTAMP`.
- **JSON Fields:** Converted from text columns (e.g., `options`, `fee_slots`, `charge_presets`) to native PostgreSQL `JSONB` for binary indexing and path querying.
- **Financial Paise:** Maintained as `BIGINT` whole paise integers across all tables (`total_paise`, `consultation_fee_paise`, `unit_cost_paise`). This preserves strict financial accuracy without floating-point drift.
- **Tax Rates:** Modeled as `NUMERIC(5,2)` to support statutory percentage rates (e.g. `2.50%`, `6.00%`, `12.00%`).

## 2. Structural Extensions
1. **Multi-Tenant Scoping:**
   - Introduced `global.organization_memberships` and `global.user_roles` with `branch_id`, `region_id`, and `inventory_id` resource columns.
2. **Region & Inventory Hierarchy:**
   - Replaced flat branch-bound inventory with `public.regions`, `public.inventory_locations`, and `public.region_inventory` M:N junction table.
3. **Statutory GST Billing:**
   - Extended flat `op_bill` into normalized `public.invoices`, `public.invoice_lines`, and `public.invoice_tax_lines`.
   - Introduced `master.gst_rates` and `master.hsn_sac_codes` for compliance auditing.
4. **Staging Schema:**
   - Added `staging.inventory_import_batches` and `staging.vendor_invoice_imports` for pre-validation of Excel uploads.
