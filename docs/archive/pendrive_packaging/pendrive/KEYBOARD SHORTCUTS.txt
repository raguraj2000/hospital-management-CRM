HMS - KEYBOARD SHORTCUTS
========================

Press  ?  (Shift + /) on any screen to see this list inside the app.
The numbers in the side menu are not shortcut keys: they show how many
patients or tests are waiting on that page.
The key is also written on the button or inside the search box.


EVERYWHERE
  F2              Billing
  F3              Pharmacy
  Alt + 1 ... 9   Open the 1st ... 9th page of the side menu,
                  counted from the top
  Alt + N         Register a new patient
  Esc             Close a window
  ?               Show the shortcut list


OP VISITS
  Alt + C         Call the next patient in


A VISIT (DOCTOR)
  Alt + C         Start the consultation
  Alt + B         Add a bookmark (ready-made treatment)
  Alt + M         Add a medicine
  Alt + L         Send to lab (on the Lab tab)
  Alt + S         Create prescription & send to pharmacy
                  (on the Preview step)


PHARMACY - DIRECT SALE
  Alt + M         Search a medicine to add
  Alt + R         Add what the patient bought last time
  Alt + S         Sell


LAB RESULTS
  Alt + S         Save & complete


BILLING AND PHARMACY CHECKOUT
  Enter           In the amount box: collect the payment


IN ANY SEARCH LIST
  Up / Down       Move in the list
  Enter           Pick
  Esc             Close the list


NOTES
  - "/" and "?" work only while you are not typing in a box.
  - Alt keys work even while you are typing.
  - Use Google Chrome or Microsoft Edge.
